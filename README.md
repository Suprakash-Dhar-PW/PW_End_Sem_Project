# PW IOI - Student Dashboard Platform

## Overview

PW IOI is a comprehensive web-based student dashboard platform designed to help students manage their academic journey, track progress, collaborate on projects, and engage with their educational community. The platform offers a wide range of features to enhance the student experience and improve productivity.

## Features

### Core Features

- **Student Dashboard**: Personalized overview of academic progress, upcoming tasks, and important announcements
- **Task Manager**: Create, organize, and track academic and personal tasks with priority levels and due dates
- **Attendance Tracking**: Monitor and manage student and mentor attendance records
- **Project Management**: Showcase, collaborate, and track progress on academic and personal projects
- **Job Portal**: Access to internship and job opportunities relevant to students' fields of study
- **Announcements**: Stay updated with important institutional announcements
- **Community Events**: Discover and participate in upcoming community and academic events
- **Notes**: Create, organize, and access study notes and resources
- **DSA Tracker & Leaderboard**: Track progress in Data Structures and Algorithms practice and compete with peers

### Additional Features

- **Portfolio**: Build and showcase personal portfolios highlighting skills and achievements
- **Community**: Connect and interact with peers and mentors
- **Leave Form**: Submit and track leave requests
- **Gallery**: Access to media resources and memories
- **Help Center**: Get assistance and support when needed
- **Settings**: Personalize the platform experience

## Getting Started

### Prerequisites

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Python (if running the backend)

### Installation

1. Clone the repository
   ```
   git clone https://github.com/yourusername/pw-ioi.git
   ```

2. Navigate to the project directory
   ```
   cd pw-ioi
   ```

3. If there's a Python backend, install dependencies
   ```
   pip install -r requirements.txt
   ```

4. Start the server
   ```
   python app.py
   ```

5. Open your browser and navigate to `http://localhost:5000` (or the port specified in the application)

## Usage

1. **Login/Sign Up**: Create an account or log in to access the dashboard
2. **Navigate**: Use the sidebar to access different features
3. **Personalize**: Customize your experience through the settings page
4. **Engage**: Participate in community events, track your progress, and manage your tasks
